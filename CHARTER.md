## 19. Execution Doctrine

The execution doctrine is:

> Signals do not equal trades.
> Trades require authorization.
> Authorization requires risk clearance.
> Risk clearance requires protocol compliance.
> Execution requires receipt.
> Receipt becomes memory.

Execution flow:

```text
Market Signal
→ Signal Agent
→ Signal Score
→ Risk Agent
→ Strategy Protocol
→ Trade Authorization
→ Execution Agent
→ Venue/Broker/Chain
→ Trade Receipt
→ Portfolio Update
→ Memory Writeback
```

This is the core loop.
